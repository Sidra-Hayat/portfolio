CUI Room Scheduler — Classroom Booking System

Room booking that can't double-book, built on one rule. Semester project, not deployed.

At my campus, finding a free room means a spreadsheet and a WhatsApp group. A room counts as taken if a class or a pending booking overlaps the time you asked for — so two slots that touch are fine, but a real clash is refused. It checks again when an admin approves, otherwise someone could approve a request that had already gone stale. Public room finder, teacher requests, admin timetable editing, and tests over the booking flow.
